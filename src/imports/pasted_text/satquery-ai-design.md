Design a high-fidelity desktop web application called “SatQuery AI”, an AI-powered geospatial intelligence platform for analyzing satellite imagery through natural-language questions. The product allows users to upload satellite imagery such as GeoTIFF files, ask questions in plain English, and receive visual, evidence-backed AI answers. It supports single-image analysis, multi-temporal/change detection, and multi-sensor analysis such as Optical + SAR. The interface should feel like a combination of Google Earth, a modern AI assistant, and a professional geospatial intelligence dashboard. IMPORTANT DESIGN DIRECTION: - Dark premium geospatial interface - Deep navy/near-black background - Earth/satellite imagery should dominate the visual experience - Subtle cyan/teal accents for active AI states, selected map regions, detections and overlays - Glassmorphism only lightly; keep the interface professional and scientific rather than overly futuristic - Clean typography similar to Inter - Rounded 10–14px cards - Thin borders - Subtle shadows - High information density without feeling cluttered - Desktop-first, designed for 1440px width - Avoid generic SaaS dashboard design - The MAP is the primary workspace Create the following complete user flow and screens. ==================================================== SCREEN 1 — SATELLITE DATA UPLOAD ==================================================== Create an immersive full-screen landing/upload workspace.
